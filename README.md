# 3x-ui Railway (نسخه فیکس شده - نهایی)

## مشکل حل‌شده
خطای `Address in use` روی پورت ۸۰۸۰ حل شد.

## تغییرات مهم

- پورت اینباند به **۸۰۸۱** تغییر کرد (تا با nginx تداخل نداشته باشه)
- حالا می‌تونی **هر Path دلخواهی** استفاده کنی
- IP Limit در پنل باز و قابل ویرایش است
- تنظیمات فقط یک بار اعمال می‌شه

---

## نحوه دیپلوی (دوباره)

1. فایل‌های جدید رو در گیت‌هاب آپلود کن
2. در Railway **Redeploy** بزن
3. **Target Port** را روی `8080` بگذار (پورت nginx)

---

## تنظیمات Inbound (خیلی مهم!)

در پنل یک Inbound جدید بساز با این تنظیمات **دقیق**:

| فیلد             | مقدار              |
|------------------|--------------------|
| **Protocol**     | VLESS              |
| **Listen Port**  | **`8081`**         |
| **Listen IP**    | `0.0.0.0`          |
| **Network**      | `ws`               |
| **Security**     | `none`             |
| **Path**         | `/cdn` (یا هر چی)   |

> **نکته:** حتماً پورت `8081` بزن (نه 8080)
